## Revenue & customers
- `sales@` — inbound leads, quote drafts, CRM writes; external parties already email sales
   - triage an inbound request from marketing
- `support@` — ticket triage, policy answers, escalate with account context
   - Knowledge Base Access + ticket workflow, 
- `crm@` — you already sketched this: forward threads → structured contact/company facts
- `legal@` / `contracts@` — NDA/MSA review drafts, obligation extraction, never send without approval
- `billing@` / ar@ — invoices, dunning, “did they pay?”; vendors/customers email this naturally
- `ap@` — vendor bills in → match PO → accounting escalation (pair with accounting@)

## Ops & “keep the lights on”

- `help@` — “what can which agent access?” (platform face)
- `approvals@` or per-agent queues — the escalation surface accounting@ needs
- `audit@` — read-only grant/MCP usage log for humans and regulators
